Bar Website Templates
酒吧網站模板

Free templates for small bars — an ordering system, a photo menu and a daily activities page. Try each one below, no sign-up needed.

中小型酒吧免費模板 — 點餐系統、相片酒單、每日活動頁。下面三個都可以即刻試玩，唔使註冊。

Ordering demo runs entirely in your browser. On this static demo site there is no PHP backend, so orders are stored only in your browser and never sent anywhere. Deploy the same files on any PHP host and the real server takes over automatically.
點餐試玩版完全喺你個瀏覽器入面跑。呢個靜態試玩站冇 PHP 後端，訂單只會儲喺你個瀏覽器，唔會傳去任何地方。同一套檔案放上任何支援 PHP 嘅主機，就會自動用返真正嘅伺服器。

Bar Ordering System點餐系統

Guests order from their phones; the bar sees orders live and marks them done. Payment stays at the bar — no online payment.

客人用手機落單，吧台即時見到、逐張完成。錢照舊喺吧枱俾，冇接網上付款。

Try it 試下： browse the menu, add drinks, submit an order — then open the bar screen with PIN 1234 to see it arrive.
